# FitTrack

FitTrack is a simple Fitness & Food Tracker website for gym users to keep track of their daily food.

## Files

- `index.html` - website structure
- `style.css` - website design
- `script.js` - JavaScript work

## JavaScript Features

- Add food with name and quantity
- Show added food in a list
- Delete food from the list
- Update total meal count on the dashboard
- Save food in the browser using localStorage

## How to Run

Open `index.html` in a browser.
